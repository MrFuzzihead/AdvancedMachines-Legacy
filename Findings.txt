1. Does Advanced Machines follow IC2's config for the wrench and percent chance for the machine to break instead of drop?

2. Do Advanced Machines require transformers ever? I can run an MFSU directly into an Advanced Machine via Glass Fibre Cable, and it doesn't explode, it works normally.

3. Let's remove the supplements system entirely from the codebase, as well as removing it from the GUI png assets

--- Resolution, second pass (assistant) ---

1. YES on both counts. The mod forwards IC2's `balance/ignoreWrenchRequirement` option through
   getItemDropped/damageDropped, and the machine-break chance is the base machine's inherited
   getWrenchDropRate() of 0.85 (i.e. 15% break-instead-of-drop), exactly as IC2. There is no separate
   drop-rate config in IC2 2.2.828 to honour.

2. NOT A BUG. In IC2 2.2.828 the energy tier does not explode machines: EnergyNetLocal/Grid never call
   createExplosion, the tier is only used for cable melting and voltage-drop maths, and the legacy
   IEnergySink.injectEnergy accepts any amount. A base IC2 Macerator fed from an MFSU via glass fibre
   behaves the same way, so no transformer is required for the machine (only for cables that are below
   the packet tier). Transformer/voltage gating would be a new feature.

3. DONE. The supplement system has been removed entirely: MaceratorSupplement, ContainerAdvancedMacerator,
   the supplement slot/state/recipes, the supplement-only output path and its tests. The Rotary
   Macerator now uses the shared ContainerAdvancedMachine and is a faster macerator with a second output
   slot. The supplement slot graphic was erased from GUIRotary.png.
